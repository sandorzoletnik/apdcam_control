Conventions

Nomenclature
Shot
The collection of the values of all channels (pixels) which were recorded at the same time
Indexing
In the C++ code 0-based indexing is used everywhere. Naturally for C++ arrays, vectors, etc, but also for the numbering of the channels.
Variable names
  • Loop indices are verbose. Instead of using i as the loop index, I tried to use indices like i_adc (index running over the ADC boards), etc

Inter-thread synchronization

The DAQ system uses threads. Individual threads read UDP packets and store them in separate buffers for each stream (ADC board). Subsequently, UDP packets from these buffers are consumed by individual threads which extract the channel data, and push them into channel data buffers, one for each channel separately. Then a common processor thread consumes this data, calling the specified tasks in a loop, and removing those shots (channel data) which all tasks reported as "not needed anymore". Currently, inter-thread synchronization is implemented by spin-locks on the buffers
